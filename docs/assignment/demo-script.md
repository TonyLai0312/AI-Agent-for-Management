# Two-minute demo script

Run this with the labelled fixture workflow. Do not present a failed live connection as successful research. Timing is a 120-second target, not a measured recording duration.

| Time | Screen / operation | Narration |
| --- | --- | --- |
| 0:00–0:15 | Login / overview | “EVOX Prospect Copilot supports a GM and BDR. Hosted mode uses assigned accounts. This walkthrough uses clearly labelled test companies; real prospect outreach is always sent manually.” |
| 0:15–0:35 | Target profile and shortlist | “Mandatory geography, industry and scale criteria decide eligibility. Technology and recent buying signals are preferences. Fit score and evidence confidence are separate. Unknown mandatory facts need verification; we return fewer than ten when fewer qualify.” |
| 0:35–0:55 | Contact and industry review | “BDR checks the person, current role and company entity, then confirms industry. No reliable contact produces a manual-search task. Conflicting industry evidence blocks progress until it is resolved with a reason.” |
| 0:55–1:15 | Customer evidence and drafting | “A logo cannot support a customer-result claim. BDR approves an exact customer claim and scope, or explicitly chooses no reference. Drafts show their supporting evidence, version and final character count. Edits need fresh approval.” |
| 1:15–1:35 | Case 5 before/after evidence | “Our evaluation found a real failure: fifty percent written as words bypassed the original number check. We preserved the failed result, improved the validator and reran the identical input. Ten curated fixture cases now pass; this is not a live research accuracy score.” |
| 1:35–1:50 | Follow-up tracker | “The deadline starts at the actual manual invitation send time and skips weekends and configured holidays. One persistent alert is claimed atomically. A late Accepted update resolves it and routes to LinkedIn, without another invitation.” |
| 1:50–2:00 | Evaluation / deployment status | “Local authentication, role restrictions and restart persistence passed. Live OpenAI is blocked by authentication; Gmail and Render account setup remain pending. Our evidence records these limits rather than substituting a demo success.” |

Before recording: keep credentials outside the browser view; use the stored synthetic cases; have the before/after JSON and screenshots open. Do not enter a fictional actual send time into a live prospect record. To demonstrate future deadlines, use the admin-authenticated isolated test namespace only.
